
# NPORT Explorer

A React dashboard for exploring SEC N-PORT filings, fund portfolio holdings, and portfolio composition.

## Features

- Search funds by CIK
- View fund financial summaries and holdings
- Explore portfolio composition and geographic exposure
- Interactive holdings table and charts

## Tech Stack

- React
- Vite
- Bootstrap
- AG Grid
- Recharts

## Local Development

```bash
git clone https://github.com/j-soto35/nport-ui.git
cd nport-ui
npm install
npm run dev
```
